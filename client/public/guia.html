Sección 1

El tridente de datos y formularios

Combinaciones potentes: cada librería hace una cosa muy bien, y juntas cubren lo que vas a hacer en casi cualquier app: traer datos del servidor y mandarle datos validados.

TanStack Query + Axios

Pedir datos al servidor… sin escribir 40 líneas de useEffect

📡 Axios = el mensajero

Hace la petición HTTP: arma la URL, headers, convierte a JSON y maneja errores de red.

🧠 TanStack Query = el cerebro

Decide cuándo pedir, guarda la respuesta en caché y te avisa el estado.

  • ✅Caché automática: si dos componentes piden los mismos datos, se hace una sola petición.
  • ✅Estados listos: isLoading, isError, data sin crear 3 useState.
  • ✅Reintentos: si falla, reintenta solo (3 veces por defecto).
  • ✅Sincronización: refresca los datos al volver a la pestaña o tras una mutación.
💡 Idea clave: la queryKey es el "nombre" de los datos en la caché. Si cambia (ej. otro id), Query vuelve a pedir.

Sección 2

Backend y subida de archivos

React vive en el navegador; los archivos se guardan en el servidor. Hay que cruzar ese puente.

Multer Node.js · Express

Recibir archivos multipart/form-data en Express

express.json() entiende JSON, pero no archivos. Multer es un middleware que lee el cuerpo multipart/form-data, guarda el archivo (en disco o memoria) y te lo deja listo en req.file.

1 · React
<input type="file"> → arma un FormData
→
2 · HTTP
POST con multipart/form-data (Axios)
→
3 · Multer
Parsea, filtra y guarda en /uploads
→
4 · Tu ruta
Usa req.file y responde la URL
⚠️ Errores típicos:
  • El nombre en formData.append('avatar') debe coincidir con upload.single('avatar').
  • Siempre limitá tamaño y tipo de archivo: nunca confíes en el cliente.
